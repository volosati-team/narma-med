# МЕДПОМОЩЬ — НАРМА 2026

Медицинские материалы фестиваля НАРМА 2026: инструкции по первой помощи,
протоколы, списки аптечек на закуп и листы для печати. Уровни по повышению:
**пост → группа постов → производственная площадка → фельдшер**.

Каждый уровень = **аптечка (что собрать)** + **лист (что распечатать)**. Всё
начинается со звонка: 112 → врач площадки → фельдшер.

## Юридическая модель

Жёсткое разделение на **первую помощь** (немедики: волонтёры, монтажники,
бригадир, фельдшер) и **медицинскую помощь** (только врач площадки, фельдшер —
под его началом). Немедик оказывает первую помощь по Приказу Минздрава РФ от
03.05.2024 № 220н; состав аптечек первой помощи работникам — Приказ от
24.05.2024 № 262н; аптечки спасателей — Приказ от 20.05.2024 № 246н.

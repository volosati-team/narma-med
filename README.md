## Юридическая модель

Жёсткое разделение на **первую помощь** (немедики: волонтёры, монтажники,
бригадир) и **медицинскую помощь** (только врач/фельдшер). Немедик оказывает
первую помощь по Приказу Минздрава РФ от 03.05.2024 № 220н; аптечки первой
помощи работникам — Приказ от 24.05.2024 № 262н; аптечки спасателей — Приказ
от 20.05.2024 № 246н.

Полные внутренние протоколы феста (мастер-док, пакет врача, укладка
фельдшера) — внутренний документ, не публикуются.

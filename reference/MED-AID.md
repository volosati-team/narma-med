# Медпомощь на фесте НАРМА 2026 — полный док

**ВНУТРЕННИЙ ДОКУМЕНТ. НЕ ДЛЯ ОБЩЕГО ДОСТУПА.** Не публикуется, не передаётся
третьим лицам, не выкладывается в открытые материалы феста.

Мастер-документ: сводит в одну цепочку уровней материалы владельца —
`MED-PROTOCOL` (msg 2219), `DOCTOR-PACKAGE` (msg 2220), `FELDSHER-KIT`
(msg 2222/2224). Каждый уровень = **аптечка (что собрать)** + **лист (что
распечатать и повесить)**. Уровни по повышению: **пост → группа постов →
производственная площадка → мне**.

Готовые листы для распечатки на каждый уровень — в `sheets/` (`LEVEL1-POST`,
`LEVEL2-GROUP`, `LEVEL3-SITE`, `LEVEL4-FELDSHER`), каждый со своей
инструкцией и списком аптечки.

**Юридическая модель:** жёсткое разделение на Первую помощь (немедики:
волонтёры, монтажники, бригадир, фельдшер) и Медицинскую помощь под
прикрытием штатного врача площадки. Локация: городская черта, рыночная зона,
СМП > 30–60 мин.

**Цепочка реагирования:** пост → старший группы → фельдшер (Андрей) → врач
площадки → СМП. Каждый уровень знает следующего: на кого кричать и кого ждать.

## Уровень 1. Пост (городская точка)

Один-два волонтёра, первая помощь до приезда СМП. На пост — аптечка + лист.

### Аптечка поста (100% легальная)
| Позиция | Кол-во |
|---|---|
| Жгут кровоостанавливающий (CAT / Эсмарха) | 2 |
| Бинт марлевый стерильный 7×14 см | 4 |
| Пакет перевязочный индивидуальный (ППИ / Израильский 4") | 2 |
| Салфетки марлевые стерильные | 1 уп. |
| Лейкопластырь рулонный тканевый (широкий) | 1 |
| Ножницы тактические (тупоконечные) | 1 |
| Перчатки нитриловые | 4 пары |
| Покрывало спасательное (фольга) | 2 |
| Хлоргексидин 0,05% | 2 фл. |
| Маска-плёнка для ИВЛ | 2 |

**Запрещено в аптечке поста: любые таблетки, капли, ампулы, мази (даже
анальгин и аспирин).**

### Лист поста (распечатать, повесить)
1. **Безопасность:** оцени обстановку. Не подходи, если есть угроза твоей
   жизни.
2. **Вызов СМП (112):** точный адрес/ориентир, пол, примерный возраст,
   причина («упал», «без сознания», «сильное кровотечение»).
3. **Критическое кровотечение** (кровь струёй / быстро пропитывает одежду):
   жгут **выше раны**, затяни до полной остановки. **Время наложения —
   маркером на лбу.** Не снимать до медиков.
4. **Без сознания, но дышит:** на бок (стабильное боковое положение). Не
   оставлять на спине — захлебнётся рвотой, западает язык.
5. **Без сознания и не дышит:** СЛР **30 нажатий : 2 вдоха** через маску,
   без остановки до приезда СМП.
6. **Шок/холод:** оберни фольгой, блестящей стороной к телу. Не поить.
7. **Один на посту?** Стабилизируй (боковое положение, кровь остановлена) →
   выбегай встречать СМП → вернись, доложи.

**Запрещено:** тащить/сажать/переворачивать при падении с высоты; вправлять
переломы; вытаскивать предметы из ран; поить; давать любые медикаменты;
снимать или ослаблять жгут.

## Уровень 2. Группа постов

Несколько постов под старшим группы. Аптечки на постах укомплектованы
(Уровень 1); группа дополнительно держит реанимационный набор и карту постов.

### Аптечка группы (дополнительно к аптечкам постов)
| Позиция | Кол-во |
|---|---|
| Турникеты (резерв) | 2 |
| ППИ / Израильский бандаж 4" | 2 |
| Бинты марлевые | 4 |
| Перчатки нитриловые | 4 пары |
| Маска-плёнка для ИВЛ | 2 |
| Покрывало спасательное (фольга) | 2 |
| Хлоргексидин 0,05% | 2 фл. |
| Карта постов группы + список номеров (112, фельдшер, координатор) | 1 |

### Лист старшего группы (распечатать, держать при себе)
1. **Знай свои посты:** где стоит каждый, кто на нём, есть ли связь.
2. **Контроль комплектности:** в начале смены проверить аптечки постов,
   пополнить. Пустая аптечка = нет поста.
3. **При ЧП на посту:** пострадавший у волонтёра — держи его (жгут/боковое/
   СЛР по листу поста), **сразу кричи фельдшера** и вызывай СМП с точными
   координатами поста.
4. **Координация:** назначь, кто держит пострадавшего, кто встречает СМП,
   кто провожает фельдшера/врача на точку.
5. **Эвакуация:** если фельдшер решает везти навстречу СМП — обеспечь
   провожатого до точки встречи.
6. **Сам на посту и случай тяжёлый, а фельдшер далеко:** действуй по листу
   поста до его прихода, не бросай пострадавшего.

## Уровень 3. Производственная площадка (монтаж)

Монтаж, высота, тяжёлые конструкции. Здесь же — лабораторный кислород и
доступ врача. На площадку — расширенная аптечка + листы монтажника и
бригадира.

### Аптечка площадки
**Бригадная (расширенная):**
| Позиция | Кол-во |
|---|---|
| Турникеты кровоостанавливающие (CAT) | 4 |
| Гемостатический бинт (Гемофлекс / с цеолитом-каолином) | 2 |
| Израильский бандаж 6" (компрессионный) | 2 |
| Шины иммобилизационные гибкие (SAM Splint) | 2 |
| Противоожоговые гелевые салфетки (Апполо / Burnshield) | 3 |
| Ножницы тактические | 1 |
| Покрывало спасательное (фольга) | 2 |
| Хлоргексидин 0,05% | 2 |

**Бригадира (экстренные спецсредства):**
| Позиция | Кол-во |
|---|---|
| Спрей Лидокаин 10% (медицинский) | 1 фл. |
| Транексамовая кислота (ампулы) | 4 |
| Плёнка полиэтиленовая / пакеты 30–50 л | 2 |
| Армированный скотч / изолента | 1 рулон |
| Стяжки строительные (крупные) | 5 |

**Таблетки в аптечках площадки запрещены.**

### Лист монтажника (распечатать)
1. **Падение с высоты (политравма):** человек лежит — **не перемещать, не
   сажать, не переворачивать** (кроме угрозы пожара/взрыва). Риск перелома
   позвоночника. Зафиксируй голову руками в одном положении, жди врача.
2. **Травма живота (выпали органы):** петли кишечника наружу —
   **не вправлять.** Обложить чистыми салфетками, обильно смоченными
   хлоргексидином/чистой водой, неплотная повязка, укрыть плёнкой от
   высыхания.
3. **Синдром длительного сдавления** (прижало балкой >15 мин): **нельзя
   резко поднимать** — токсины из разрушенных мышц остановят сердце. Ждать
   МЧС. *Полевой протокол (СМП застряла, объект горит/рушится): перед
   подъёмом наложить жгут на придавленную конечность как можно ближе к
   паху/подмышке, только потом поднимать.*

### Лист бригадира (распечатать) — при тяжёлой травме (ампутация кисти/пальцев)
1. **Остановка крови:** жгут **на плечо (выше локтя)**, до полной остановки.
   Время — маркером на лбу.
2. **Заморозка раны:** 8–10 нажатий Лидокаина 10% на культю и разорванные
   нервы — блокирует болевой шок. Поверх — тугой Израильский бандаж.
   Поить/таблетки запрещено.
3. **Гонщик за врачом:** немедленно физически крепкий монтажник бегом в
   медпункт — взять врача и притащить к месту ЧП кратчайшим путём.
4. **Кислородная палатка** (бледность, липкий пот, тяжёлое дыхание от
   кровопотери): шланг от лабораторного баллона (поток 4–6 л/мин через
   редуктор) к углу пакета, замотать скотчем. Внутрь — кольцо из стяжки.
   Пакет на голову как свободный капюшон. **Завязывать на шее запрещено.**
5. **Ловушка ХОБЛ:** возрастной/курящий задыхается, синеет, но **травмы и
   кровотечения нет** — приступ ХОБЛ/инфаркт. **Кислород запрещён** (отключит
   дыхательный центр). Свежий воздух, посадить, ждать врача.
6. **Сохранение ампутанта (пальцы/кисть):** не мыть. Сухой бинт → пакет 1 →
   пакет 2 с холодной водой/льдом. **Мясо ко льду не прикасается.**

## Уровень 4. Мне — фельдшер (Андрей)

Старший медик на площадке до врача. Хожу/езжу между постами и площадкой с
полной укладкой. Подчиняюсь врачу площадки; без врача — по экстремальному
протоколу «рискуя свободой» с фиксацией всего в карте осмотра.

### Укладка фельдшера
Полный состав — `FELDSHER-KIT` (msg 2222/2224). Кратко:
- **Раздел 1 — легальный в РФ (база):** турникеты ×2, гемостатика ×2,
  Израильский 6" ×2, Chest Seal ×2, воздуховоды Гведела, маска-плёнка ×2,
  шины SAM ×2, фольга ×2, ножницы, перчатки, хлоргексидин; перевязочные,
  повидон-йод, уголь.
- **Раздел 2 — реально необходимый (Rx/серая зона, закрыто):** иглы 14G ×2,
  катетеры G14/16/18, инфузионные системы, NaCl/Рингер 400 мл ×4, мешок
  Амбу + O₂-баллон с редуктором и ротаметром, хирургический набор (зажимы
  Кохера ×2, иглодержатель, атравматика Нейлон/Викрил 3-0), Лидокаин 10%
  спрей; Транексам ×4, Кеторолак ×2, Адреналин ×2, Преднизолон 120 мг ×2,
  Атропин ×2, Трамадол ×2, Цефтриаксон/Амоксиклав, Диазепам/Мидазолам ×2,
  Ксилазин 2% ×1.
- **Вет-резерв (вариант предложить врачу на экстремальные случаи):**
  Кетамин, Золетил, Ацепромазин, Флуниксин, Мелоксикам, Амоксициллин LA,
  Дексаметазон. Применение человеку — только врачом, вне инструкции.

### Протоколы на критическом случае
1. **Принял вызов** → иду с укладкой; по пути бригадиру — начать остановку
   крови жгутом и гонщика за врачом.
2. **Оценка ABCDE:** Airways (западение языка → воздуховод Гведела),
   Breathing (дышит? грудь?), Circulation (пульс, кровотечение), Disability
   (сознание, зрачки — ЧМТ?), Exposure (среда, гипотермия).
3. **Кровотечение** → жгут выше раны / тампонада гемостатиком (пах, подмышка,
   шея) / давящая повязка. Время на лбу.
4. **Доступ и инфузия:** катетер (G18 — рутина, G16/G14 — шок), Рингер/NaCl.
   **Пермиссивная гипотензия:** систолическое ~80–90 мм рт. ст., выше не
   поднимать — сорвёт тромбы.
5. **Тяжёлая травма + шок:** Транексам 1000 мг болюс → доступ G16/G18 →
   Рингер → Преднизолон 120 мг → анальгезия Кеторолак в/в (**не Трамадол
   первым**).
6. **Раненая грудь:** Chest Seal (один край свободен — клапан). Нарастает
   напряжение (одышка, тишина, синюшность, смещение трахеи) → декомпрессия
   14G во 2-е межреберье по среднеключичной линии. Только обученный персонал.
7. **Психоз на стимуляторах + травма:** физическая фиксация командой,
   седацию не колоть до оценки. При необходимости — Диазепам/Ксилазин только
   врачом и под инфузией.
8. **Эвакуация:** фиксация на жёсткий щит, погрузка в пикап, врач рядом,
   навигационный «Перехват» с 112 (см. ниже).

### Анальгезия и дыхание
- Кеторолак в/в — не угнетает дыхание и зрачки, не маскирует ЧМТ.
- Трамадол — угнетает дыхание, только с контролем дыхания.
- Кислород — при кровопотере/шоке; **не давать чистый O₂ при ХОБЛ/инфаркте
  без травмы** (срывает дыхательный центр).
- Адреналин 0,3–0,5 мг в/м — анафилаксия/тяжёлый шок. Атропин 0,5–1 мг в/в —
  брадикардия.
- Отравление/передозировка перорально (в сознании): уголь активированный
  10–20 таб. разжевать с водой.

### Границы фельдшера
- Всё «серое» (внутривенный наркоз, хирургический гемостаз в ране,
  прошивание сосудов) — только врач. Я готовлю, ассистирую, фиксирую в
  «Карте первичного осмотра пострадавшего» (подпись врача и печать =
  легализация действий команды).
- Полевой протокол «рискуя свободой» — только в экстремальном случае (жгут
  >2 ч и до эвакуации далеко: гемостаз в ране зажимом + прошиванием, затем
  ослабить жгут), с полным пониманием юридического риска и фиксацией.
- Вет-препараты предлагаются врачу как вариант на экстремальные случаи —
  применение человеку строго по его решению.

## Врач площадки — ступень выше

Блок «шёпотом»: выдаётся врачу лично на ухо на критическом случае, полностью
легализует его манипуляции дипломом. Полный текст — `DOCTOR-PACKAGE` (2220).

### Скрытые ресурсы
1. **Кислород «5 девяток» (99.999%)** из лаборатории хроматографов: редуктор
   низкого давления с ротаметром, ~0.01 бар, шланг + мешок Амбу. При шоке и
   кровопотере — неограниченный O₂.
2. **Ветеринарный Ксилазин 2% (Ксила/Рометар):** не входит в Список II НС и
   ПВ — нет ст. 228 за оборот. Мощная седация в/м в половинной дозе при
   солевом психозе — **строго под прикрытием капельницы** (роняет АД).
3. **Ветеринарная атравматика** (Нейлон 3-0, Викрил 3-0) + зажимы Кохера/
   Бильрота: окончательный гемостаз в ране — зажать магистральный сосуд,
   прошить наглухо, распустить жгут, сохранить конечность.

### Тактика «Перехвата» (борьба с рыночными пробками)
- **Лимит на месте ≤10–15 мин:** монтажники держат, бригадир — жгут +
  Лидокаин, врач — Трамадол + Преднизолон 120 мг в/в + катетер G16 + Рингер.
- **Пермиссивная гипотензия 80–90 мм рт. ст.**, пульс на лучевой едва
  прощупывается — не сорвать тромбы.
- **Эвакуация навстречу:** пострадавший на жёсткий щит → в пикап → врач
  рядом → движение через служебные выезды к точке встречи вне затора.
  Я веду навигационный перехват по 112: «Пикап госномер X, движемся
  навстречу, ждите на перекрёстке Y через 7 минут».

### ХОБЛ-фильтр
Монтажники и бригадир кислород **не трогают** при удушье/болях в груди без
механической травмы. Врач прибегает со своим пульсоксиметром и настраивает
низкопоточную подачу 1–2 л/мин под контролем сатурации 88–92%.

### Чек-лист встречи с врачом (до монтажа)
1. [ ] Договор и юридическая ответственность врача на площадке.
2. [ ] Состав его официальной аптечки (Трамадол, Пропофол, Преднизолон,
      катетеры, Рингер) одобрен.
3. [ ] Лабораторный кислородный редуктор проверен (безопасность давления).
4. [ ] Личное согласие на ветеринарный Ксилазин при критическом психозе.
5. [ ] Одобрена вет-атравматика (Нейлон/Викрил) для экстренного гемостаза.
6. [ ] Точка «перехвата» со СМП вне рыночной пробки утверждена.

## Шпаргалка (критические алгоритмы)

- **Кровотечение → жгут** выше раны, время на лбу. Не снимать до медиков.
  Жгут >2 ч и до эвакуации далеко → гемостаз в ране (зажим + прошивание) с
  последующим ослаблением жгута — врач, в экстриме фельдшер «рискуя
  свободой».
- **Инфузия (пермиссивная гипотензия):** систолическое АД 80–90 мм рт. ст.
  до остановки внутреннего кровотечения. Выше — сорвёт тромбы.
- **Тяжёлая травма + шок:** Транексам 1000 мг → доступ → Рингер →
  Преднизолон 120 мг → Кеторолак в/в (не Трамадол первым).
- **Раненая грудь:** Chest Seal → нарастает напряжение → декомпрессия 14G.
- **Психоз на стимуляторах:** фиксация командой, седацию не колоть до
  оценки; при необходимости — Диазепам/Ксилазин врачом под инфузией.
- **ХОБЛ-ловушка:** пожилой/курящий задыхается без травмы — кислород НЕ
  давать, свежий воздух, ждать врача.

## Дисклеймер

Заготовка по ТССС-протоколам и материалам владельца (msg 2209/2219/2220/
2222/2224). Итоговый состав и применение — только после согласования с врачом
площадки (чек-лист — `DOCTOR-PACKAGE`). Раздел 2 укладки и вет-резерв —
рецептурные и «серые» позиции: требуют медицинской квалификации и несут
правовой риск; применение — только врачом площадки, либо фельдшером по его
прямому указанию, либо в экстремальном протоколе «рискуя свободой». За ошибки
применения несёт исполнитель и ответственный врач.

## Инструкция / протоколы

1. **Принял вызов** → иду с укладкой; по пути бригадиру — начать остановку
   крови жгутом и гонщика за врачом.
2. **Оценка ABCDE:** Airways (западение языка → воздуховод Гведела),
   Breathing (дышит? грудь?), Circulation (пульс, кровотечение), Disability
   (сознание, зрачки — ЧМТ?), Exposure (среда, гипотермия).
3. **Кровотечение** → жгут выше раны / тампонада гемостатиком (пах, подмышка,
   шея) / давящая повязка. Время на лбу.
4. **Доступ и инфузия:** катетер (G18 — рутина, G16/G14 — шок), Рингер/NaCl.
   **Пермиссивная гипотензия:** систолическое ~80–90 мм рт. ст., выше не
   поднимать — сорвёт тромбы.
5. **Тяжёлая травма + шок:** Транексам 1000 мг болюс → доступ G16/G18 →
   Рингер → Преднизолон 120 мг → анальгезия Кеторолак в/в (**не Трамадол
   первым**).
6. **Раненая грудь:** Chest Seal (один край свободен — клапан). Нарастает
   напряжение (одышка, тишина, синюшность, смещение трахеи) → декомпрессия
   14G во 2-е межреберье по среднеключичной линии. Только обученный персонал.
7. **Психоз на стимуляторах + травма:** физическая фиксация командой,
   седацию не колоть до оценки. При необходимости — Диазепам/Ксилазин только
   врачом и под инфузией.
8. **Эвакуация:** фиксация на жёсткий щит, погрузка в пикап, врач рядом,
   навигационный «Перехват» с 112 (врач площадки, `../DOCTOR-PACKAGE.md`).

**Анальгезия и дыхание:** Кеторолак в/в — не маскирует ЧМТ. Трамадол —
угнетает дыхание, только с контролем дыхания. Кислород — при кровопотере/
шоке; **не давать чистый O₂ при ХОБЛ/инфаркте без травмы**. Адреналин
0,3–0,5 мг в/м — анафилаксия/шок. Атропин 0,5–1 мг в/в — брадикардия.

**Границы:** всё «серое» (наркоз, хирургический гемостаз в ране,
прошивание сосудов) — только врач. Я готовлю, ассистирую, фиксирую в «Карте
первичного осмотра пострадавшего» (подпись врача + печать = легализация).
Полевой протокол «рискуя свободой» — только в экстриме (жгут >2 ч и до
эвакуации далеко), с фиксацией. Вет-препараты — только по решению врача.
